# Product Proposal

> **Статус:** на согласовании (гейт Г1). Код приложения пишется только после одобрения концепции и архитектуры.
>
> **Рабочее название:** Carrel — личный тихий стол для учёбы в библиотеке. Название ещё не утверждено.

**Carrel** — нативное приложение для iPad, где пишут от руки Apple Pencil. Оно открывается сразу, не теряет ни строчки и не берёт подписку за базовые функции. Главный сценарий — конспекты лекций на русском и английском с формулами, схемами, слайдами PDF и аудио. Дневник и планирование работают на той же основе.

## Уже решено

| Тема | Решение |
|---|---|
| Платформа | iPad, iPadOS 27 и новее. Только в 27 есть распознавание рукописи `PKStrokeRecognizer` на устройстве, стабильные ID штрихов и API выделения лассо. Сборка — Xcode 27 |
| Устройство для проверки | iPad Air на чипе M с Apple Pencil Pro, экран 60 Гц |
| Проверка сборки | GitHub Actions на macOS и Mac владельца |
| Главный сценарий | Учёба и лекции; рукопись на русском и английском, формулы и схемы |
| Релизы | MVP — без PDF, аудио, синхронизации и ИИ. 1.0 — PDF, аудио, синхронизированное со штрихами, синхронизация iCloud. 1.1 — ИИ |
| ИИ | Необязателен и выключен по умолчанию. Модели Apple на устройстве плюс OpenAI с ключом пользователя в Keychain |
| Язык интерфейса | Английский; все строки в String Catalogs, русский добавляется переводом |
| Сохранность | При сбое теряется не больше 5 секунд непрерывного письма, при сворачивании — ничего |
| Бюджет на сервисы | $0: только инструменты Apple, без сторонних зависимостей и SDK аналитики |
| Монетизация | Решается позже; базовые функции не уходят под подписку |
| Репозиторий | Публичный, код под MIT, © Devlet Boltaev; коммиты сразу в `main` |
| Идентификаторы | `dev.devlet.notebook`, `dev.devlet.notebook.package`, `iCloud.dev.devlet.notebook` — не меняются никогда, даже при смене названия |

## Что нужно решить на Г1

Полный список из 12 вопросов — в [10.1](04-roadmap.md#101-этапы-работы). Главные из них:

1. Рабочее имя: Carrel или Sheaf.
2. Настроение интерфейса; рекомендуем Reading Room.
3. Объём MVP и критерий готовности: две недели лекций только в приложении, без возврата в Goodnotes.
4. Сколько сфокусированных дней в неделю уходит на проект. Оценка MVP — 62–67 дней работы до спайков, от этого числа зависит календарь.
5. Mac на Apple silicon с macOS Tahoe 26.6 или новее для Xcode 27 и iPad, обновлённый до iPadOS 27.

## Как проверялись факты

Факты о платформах Apple сверены с документацией developer.apple.com и материалами WWDC на октябрь 2026 года. Цены конкурентов взяты с официальных страниц. То, что подтвердить не удалось, помечено в тексте словом «проверить» и стоит в плане спайков. Главное из непроверенного — есть ли русский язык в `PKStrokeRecognizer.supportedLanguages`. Это проверяется первым спайком на iPad владельца: симулятор распознаёт только латиницу.
