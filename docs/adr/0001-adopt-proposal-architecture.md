# 1. Adopt the architecture from the product proposal

- Status: accepted
- Date: 2026-11-01

## Context

The product proposal ([part 3](../proposal/03-architecture.md)) records ADR-01 to ADR-15: file packages as the
source of truth, the ink envelope, atomic writes, autosave limits, the canvas under SwiftUI, sync readiness and
the rest. They were reviewed and approved together with the proposal.

## Decision

All decisions in part 3 are accepted as written. New decisions get their own record in this folder, numbered
in order, using this file as the template: context, decision, consequences.

## Consequences

The proposal stays the reference for decisions made before development started; this folder records
everything decided after.
